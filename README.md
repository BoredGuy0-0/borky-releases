# Borky releases

Downloads for Borky, an Android app whose mischievous lime mascot interrupts
excessive social media use. This repository holds release files only.

## Latest: 0.1.1 (Beta)

- Download `borky-0.1.1.apk` from the Releases page
- Requires Android 8.0 or newer
- Size: 8.8 MB
- SHA-256: `C5E7A23960038EC129F1DEC66A9E3615E9CFD38BDD9D98DB85D961708B76FAFA`

## Permissions

- Usage access: see which app is open and today's usage
- Display over other apps: show Borky on top of that app
- Notifications: show that monitoring is running
- Foreground service and start at boot: keep monitoring running

Borky has no internet permission. Your data stays on your phone.

## Known issue

Some phones, including vivo, may stop Borky in the background. If monitoring
turns off, open Borky to restart it.
